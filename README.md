# 栖砂 · 田园记（Sand Garden / Farm Life）

一块田，一季慢生活。一款纯农场的原创像素游戏：开垦、播种、浇水、采收、卖钱，和村民阿禾一起把荒地过成田园。

零运行时依赖，全部运算在浏览器本地完成。整个游戏是**一个自包含的 HTML 文件**（源码、样式、原创像素渲染，以及一张内嵌的生成插画封面全部在同一文件里），**双击 `index.html` 即可离线游玩**，不需要联网、不需要安装。

当前版本 **2.1**。项目只包含这一款农场游戏。GitHub Pages 保持关闭，不提供在线可玩版本，请下载后本地打开。

## 一天的循环

```text
开垦 → 播种 → 浇水 → 回小屋睡觉 → 作物长大 → 采收 → 出货箱卖钱 → 买种子 / 升级水壶
```

时间从第 1 天 06:00 开始，每 1 秒现实时间推进 2 分钟游戏时间，最晚到 22:00；到点会提醒你回家，不会扣掉你的收成。睡觉会进入下一天、清空当日浇水记录、恢复满体力。

## 打开就能玩

1. 打开 `index.html`。先看到一张封面插画：没有存档时点「开始种田」，有存档时点「继续农场」直接接着玩，或点「新的农场」重新开始。
2. 往下走进浅绿色田地，选「锄头」，对着身边格子按 `空格` 开垦。
3. 按 `2` 选「种子」，在开垦好的地块播种（右侧可切换萝卜 / 胡萝卜 / 草莓）。
4. 按 `3` 换「水壶」，把每块作物浇一次水。
5. 走到小屋旁按 `E`，选「睡到明天」——只有当天浇过水的作物才会长大一天。睡醒会给出当日总结（生长了几块、体力与金币、今天的天气）。

详细流程见 [docs/PLAYGUIDE.md](docs/PLAYGUIDE.md)。

## 操作

| 操作 | 键盘 | 鼠标 / 触屏 |
| --- | --- | --- |
| 移动 | `WASD` / 方向键（按住连续走） | 点地图远处自动寻路；屏幕方向键按钮 |
| 使用工具 | `空格` | 点身边一格，或点「使用工具」按钮 |
| 交互 | `E` | 点「交互」按钮，或点右侧「村庄向导」自动走过去 |
| 切换工具 | `1`–`6` | 点工具栏 |
| 暂停 | `P` | 点「暂停」按钮 |
| 回到封面 | —— | 顶栏 `⌂` 按钮（会先自动保存） |

- 鼠标悬停或点击某块地时，底部提示会显示这块地的状态：作物名、已生长天数 / 总天数、是否已经可以采收、土地是否湿润。
- 点击小屋或杂货铺的建筑本身，也会自动走过去并触发对应的交互。
- 对话框打开时游戏时间自动暂停；点击远处会走最短路径，方向键或再次点击可随时打断。

## 六种工具

| 工具 | 体力 | 效果 |
| --- | --- | --- |
| 锄头 | 2 | 在农田范围开垦土地（农田外不能开垦） |
| 种子 | 1 | 在已开垦的空地播种（萝卜 / 胡萝卜 / 草莓） |
| 水壶 | 2 | 浇灌作物所在的地块（只浇还没湿润的）；升级后同时覆盖目标格上下左右 |
| 采收 | 1 | 收获成熟作物，进入背包，土地保留 |
| 斧头 | 6 | 砍掉树，得到 3 份木材 |
| 镐子 | 6 | 敲碎石块，得到 2 份石料 |

每次成功的动作消耗对应体力并推进 5 分钟游戏时间。体力不足、种子不够、距离太远等失败操作不会改变库存、体力或时间。

## 三种作物

| 作物 | 生长日 | 种子价 | 收成价 | 特点 |
| --- | --- | --- | --- | --- |
| 萝卜 | 2 | 12 G | 25 G | 回本最快，适合起步 |
| 胡萝卜 | 3 | 18 G | 42 G | 中期主力 |
| 草莓 | 4 | 30 G | 75 G | 单位收益最高，周期最长 |

生长规则：

- 只有「当天浇过水」的作物，在睡觉时才会生长 1 天；
- 没浇水只会暂停生长，**不会枯萎**，第二天补浇即可；
- 已经湿润的地**不用重复浇**：再浇会提示「已经湿润，不需要重复浇水」，既不耗体力，也不推进时间、不重复计入浇水统计；
- 雨天所有已开垦地块自动湿润，当天新开垦的土地也会立即湿润；
- 天气由存档种子决定，读档后未来的天气依然是同一序列。

## 村庄地点

| 地点 | 位置 | 作用 |
| --- | --- | --- |
| 小屋 | (6, 7) | 睡觉进入下一天，恢复满体力 |
| 杂货铺 | (23, 7) | 买三种种子，升级水壶 |
| 出货箱 | (10, 7) | 一次性卖出背包里所有作物 |
| 阿禾 | (20, 9) | 领取村民委托奖励 |
| 石井 | (19, 12) | 每天一次，恢复 12 点体力（体力已满时不能休息） |

走到地点相邻的一格（含斜角）即可交互，也可以点右侧「村庄向导」自动寻路过去。

## 村民委托

| 委托 | 条件 | 奖励 |
| --- | --- | --- |
| 第一篮收成 | 累计采收 4 个作物 | 60 G |
| 田园小生意 | 累计卖出 8 个作物 | 100 G |
| 勤劳园丁 | 累计浇水 20 块（升级水壶后一次可算多块） | 80 G |

条件达成后走到阿禾身边领取，每个委托只能领一次。

## 商店与升级

- 每种种子都有「买 1 份」和「买 5 份」两个按钮，价格分别为种子单价 × 1 和 × 5；钱不够时按钮不可用。核心接口单次可买 1–99 份。
- **水壶升级**：160 G + 6 份木材，之后一次浇水覆盖目标格及其上下左右。木材靠斧头砍树获得。

## 存档

| 方式 | 说明 |
| --- | --- |
| 保存 | 存到当前浏览器的 localStorage（手动存档，不会被自动存档覆盖） |
| 读档 | 弹窗里可以选择读取「手动存档」或「自动存档」 |
| 导出存档 | 下载 `栖砂田园记-第 N 天.json`，可备份或换设备 |
| 导入存档 | 读取导出的 `.json`，**文件上限 1 MiB** |

- 游戏每 30 秒自动存档一次，睡觉后、切换标签页隐藏时、回到封面时也会自动保存。
- 封面上的「继续农场」会优先读取设备上的存档（先自动存档、后手动存档），读不到时会提示改用导入。
- 导入的文件会先完整校验再整体替换当前进度；格式不对、版本不符或超大时只提示错误，**当前农场不受影响**。
- 农场存档版本为 v2，只保存农场进度；2.0 版本产生的农场存档可在 2.1 中原样读取，无需迁移。

## 封面说明

- 打开页面时的那张图是**生成插画**，仅作装饰，与玩法无关。
- 比例是 **3:2**（不是 16:9 宽屏），由 gpt-image-2.5-flare 生成。
- 构建时转成 data URI **内嵌进同一个 HTML 文件**，所以双击打开、断网也能显示，不请求任何外部图片。
- 它**不是游戏画面**：进入游戏后的农场地图由 `src/farm-renderer.js` 用 Canvas 逐格原创绘制。

## 运行与构建

直接双击 `index.html` 即可。也可以用静态服务器：

```bash
python -m http.server 8000
```

仓库是「源码 + 构建产物」结构，`index.html` 与 `sand-garden.html` 由源码内联生成，两份必须字节一致：

```bash
node scripts/build.mjs          # 由 src/ 重新生成 index.html 与 sand-garden.html（含自检）
node scripts/build.mjs --check  # 只校验现有产物与 src 是否一致，不写文件
```

构建脚本只用 Node 标准库，会检查占位符替换、封面与四个源文件是否逐字内联、canvas 尺寸、脚本顺序、无外部资源、页脚完整，以及产物中不残留旧沙盒代码。

## 测试

三套 `node:test` 测试，无第三方依赖，在仓库根目录运行；当前48项通过（农场规则34、UI行为11、纯农场产物3）：

```bash
# 农场规则（src/farm-core.js）
node --test --test-isolation=none tests/farm.test.mjs

# 真实 UI 代码行为（src/ui.js + DOM 桩）
node --test --test-isolation=none tests/ui.test.mjs

# 纯农场产物与离线封面
node --test --test-isolation=none tests/release.test.mjs
```

- `farm.test.mjs` 覆盖开垦 / 播种 / 浇水 / 采收、体力与失败不改状态、商店、委托、井边休息、水壶升级、快照往返与非法存档拒绝等核心规则。
- `ui.test.mjs` 用最小 DOM / canvas 桩加载真实 `src/ui.js`，派发真实键鼠事件检查交互行为，不重写游戏逻辑。
- 产物侧的检查由 `node scripts/build.mjs`（或 `--check`）完成：纯农场产物、封面内嵌、无外部资源等。
- 在禁止子进程的沙箱环境里，`node --test` 会因 spawn 报 EPERM，所以上面的命令加了 `--test-isolation=none`；普通机器上不加也可以。
- 测试与构建自检不等于真机验收：浏览器里的画面与手机布局仍需人工打开确认。

## 项目结构

```text
index.html / sand-garden.html   构建产物（单文件、可双击）
src/shell.html                  HTML 骨架，含封面与四个内联占位符
src/style.css                   基础界面样式（含窄屏断点）
src/art-theme.css               原创木框与旧纸美术主题
src/farm-core.js                农场规则（UMD，纯逻辑，无 DOM）
src/farm-renderer.js            原创像素渲染（canvas，无外部素材）
src/ui.js                       界面绑定、寻路、存档、封面、对话框
scripts/build.mjs               零依赖构建 + 产物自检
assets/farm-cover.webp          封面插画（构建时内联进产物）
tests/                          farm.test.mjs / ui.test.mjs / release.test.mjs
docs/PLAYGUIDE.md               玩法图文说明
```

## 实现说明

- 地图 30 × 22 格、每格 32 px，画布 960 × 704，逐帧整体重绘，像素风不做平滑。
- 规则层与渲染层分离：`FarmCore` 不碰 DOM，`FarmRenderer` 只读游戏状态，界面层负责交互与存档。
- 天气 = f(种子, 天数)，不需要额外保存随机数状态，读档后天气序列不变。
- 所有动作先校验、后落盘；失败时体力、库存、时间、地块都不变。
- 零运行时依赖，无网络请求；封面图在构建时以 data URI 内嵌。
- 浏览器控制台可用 `window.SAND_FARM` 查看状态（`SAND_FARM.state()`、`SAND_FARM.health()`）。
