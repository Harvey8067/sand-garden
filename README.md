# 栖砂 · Sand Garden

一座指尖上的小世界：撒一把沙，接一滴雨，看微小的世界慢慢生长。

纯前端单文件实现，零依赖、零素材，打开 `index.html` 就能玩。

## 玩法

这里没有任务，也没有输赢。选一种材料，在画布上按住鼠标或滑动手指，让它们相遇。

| 材料 | 行为 |
| --- | --- |
| 沙 | 下落、堆积，会沉入水中 |
| 水 | 流向低处，遇火变蒸汽 |
| 土 / 种子 | 种子落在泥土上、附近有水时发芽长成植物 |
| 木 / 叶 | 会被火点燃 |
| 火 | 点燃木头与植物，遇水变成蒸汽 |
| 冰 | 遇热融化 |
| 熔岩 | 碰到水凝固为岩石，同时产生蒸汽 |

## 操作

- 空格：暂停 / 继续
- `E`：橡皮擦
- 数字 `1`-`9`：切换材料
- `[` `]`：调整笔刷半径
- `Ctrl / Cmd + Z`：撤销
- 「存档」保存在当前浏览器；「留下此刻」导出 PNG；场景切换与清空都可撤销

## 本地运行

双击 `index.html` 即可，或起个静态服务器：

```bash
python -m http.server 8000
```

## 实现

采用元胞自动机（cellular automata）模拟，自写的引擎，没有引用任何第三方库、模型或素材。
画布为 300 x 188 的网格，逐格更新材料与寿命，树木、雨、泉眼都是引擎内的规则。

界面与代码为本项目独立实现，灵感来自开源项目 [sandspiel](https://github.com/MaxBittker/sandspiel)。
